# 数据署名与来源

《史记》古代原作：司马迁，公有领域。转录、校勘与编者说明：[维基文库及贡献者](https://zh.wikisource.org/wiki/史記)。本地版本来自 2026-03-15 EPUB 存档；每卷 JSON 和 manifest.json 保留对应原页链接。

EPUB 元数据标示 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 和 [GFDL](https://www.gnu.org/licenses/fdl-1.3.html)，部分页脚还注明 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。本站转换为按卷 JSON，删除导航与危险 HTML 属性，保留正文、年表、校勘，重排版面并生成简体检索和段落编号。

星图结构化数据另由[鲍捷及贡献者《史记知识库》](https://github.com/baojie/shiji-kb)提供，使用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 非商业许可。本站对称谓、年代、出处和数据结构进行了转换。机器整理的索引和解释仍待审校，不能视作全部已证实的历史互动。

固定版本、校验值与转换说明见源码 `data/shiji/README.md`、`data/shiji-graph/README.md`。
