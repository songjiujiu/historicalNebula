# 历史星云 · Historical Nebula

以 TypeScript、Vite 和 Three.js 构建的历史阅读与关系探索网站。现已接入《史记》130 卷全文及覆盖全书的人物、事件、篇章和关系索引，同时保留汉末三国 / 赤壁专题。

## 运行与检查

使用 Node.js 24.x，或不低于 22.12 的 Node.js 22.x。

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

打开开发服务器打印的 HTTP 地址。生产构建输出到 `dist/`，可部署至静态服务器，无需 API 密钥、数据库或远程内容服务。建议服务器启用 Brotli/gzip；完整结构化图谱使主包较大，正文则按卷加载。

## 《史记》全书接入

- **全文**：130 卷，12 本纪、10 表、8 书、30 世家、70 列传；十表保留正文表格，非仅收录序言。共 730,220 字符，包含转录校勘及编者增补，不等同于古代原作字数。
- **星图**：5,297 个人物词条、3,203 个事件、130 个篇章节点，29,276 条关联。每卷均有篇章、人物与事件入口。图谱按关联逐步探索，默认展开 12 个邻居，最多同时显示 50 个对象；全部数据均可检索。
- **阅读互通**：顶部“史记全书”打开目录；支持简繁检索、全文与年表搜索、原字/简体切换、段落定位、阅读书签、继续阅读、上下卷和链接分享。篇章、人物、事件可进入原文，原文可返回本卷或关联对象星图。
- **证据区分**：原文提及、篇章出处和互见单列“原文索引”；因果与事件衔接标记为解释。机器整理数据标示“待审校”，不会把共同提及当作已经核实的人物互动。
- **年代**：公元前 841—1 年使用时间轴。上古传统纪年及缺失年份使用“时间待考”，不捏造精确年份；篇章出处不受历史年份限制。

全书覆盖指固定版本的全文与结构化索引覆盖全部 130 卷，并不意味着已经穷尽所有历史事实或完成人物同名消歧。不同篇章对同一事件的叙述可能保留多个节点。保留原楚汉编辑样本的稳定 ID、6 个事件和 28 条关系，以兼容原有链接、收藏及导览。

赤壁专题保留 25 个实体、50 条关系、11 项来源和 3 个导览，与《史记》隔离。全站合计 8,655 个实体、29,326 条关系、141 项来源、5 个导览。版本为 `topics-shiji-full-draft-2026-09-29`。

## 数据来源与重建

正文来自[维基文库《史记》及贡献者](https://zh.wikisource.org/wiki/史記)的固定 EPUB 存档，古代原作属公有领域；EPUB 标示 CC BY-SA 3.0/GFDL，部分页脚有 CC BY-SA 4.0 提示，详见 [全文来源说明](data/shiji/README.md)。本站保留校勘与编者小节，移除导航和危险 HTML，重新排版并添加段落编号。

结构化图谱来自[鲍捷及贡献者的史记知识库](https://github.com/baojie/shiji-kb)，采用 **CC BY-NC-SA 4.0 非商业许可**，快照与派生图谱保留署名和许可。商业使用需另获授权或替换这部分数据。详见 [图谱来源说明](data/shiji-graph/README.md)。

```bash
# 使用仓库内固定快照，校验 SHA-256 后离线重建
npm run import:shiji
```

原始快照在 `data/`；生成的全文在 `public/data/shiji/`，图谱及导入报告在 `src/domain/generated/`。转换不依赖上游在线 API；更新底本需要显式更新校验值并重新验证。

## 探索与本机记录

3D 星图支持旋转、缩放、平移、居中、全屏、展开/撤销关联和列表切换；来源、时间和关系类型可筛选。收藏、保存视图、导览进度、最近探索及阅读书签保存在当前浏览器，无账号或跨设备同步。公开链接仅包含探索条件或阅读卷次/段落，不包含本机收藏。

现代浏览器需支持原生 dialog 和 WebGL 2。3D 失败时降级为列表，手机优先列表；阅读器支持手机布局，年表可横向滚动。保留三档画质、动态效果设置及系统减少动态偏好。

## 主要代码

| 路径 | 用途 |
| --- | --- |
| src/main.ts | 探索页面、导航、来源卡与阅读器互通 |
| src/domain/shiji-book.ts | 全书目录、按卷加载、检索与阅读链接 |
| src/ui/shiji-reader.ts | 阅读器、书签、简繁显示和篇章星图入口 |
| src/domain/shiji-full-data.ts | 解包全书图谱并兼容原楚汉数据 |
| src/exploration/core.ts | 搜索、年代筛选、图谱预算与状态恢复 |
| scripts/import-shiji.mjs | EPUB 清理、130 卷正文与全文索引 |
| scripts/import-shiji-graph.mjs | 人物、事件、索引关系与来源定位 |
| tests/ | 内容覆盖、引用、搜索、状态、预算和阅读交互验证 |

## 验证与边界

自动化检查覆盖 130 卷和五种体例、十表正文、HTML 清理、图谱引用完整性、搜索、年代空值、专题隔离、50 节点预算、分享、阅读加载竞态、失败重试与书签。它们不替代史料审校、真实手机性能和跨浏览器兼容性认证。完整图谱采用紧凑数据格式；生产构建仍会提示大块文件，首屏性能需在目标设备和托管环境测量。

详细结构和审校边界见 [《史记》接入技术说明](史记接入技术说明.md)，交互检查见 [开发验收记录](开发验收记录.md)。原产品与 3D 设计文档作为后续迭代参考。
