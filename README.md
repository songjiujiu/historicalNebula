# 历史星云 · Historical Nebula

以 TypeScript、Vite 和 Three.js 构建的二十四史阅读网站。《史记》130 卷有逐卷入门导读、楚汉故事和人物事件星图；新增 23 部史书、3,083 个可阅读卷次，可按朝代路线、书目与卷次阅读，并在单部史书内检索已收录转录。少数历法表仍缺录。

## 第一次阅读

主导航有“史记导读”“白话故事”“史记星图”“史记原文”和“二十四史”五个入口。

- **二十四史**：从《汉书》到《明史》的 23 部新增史书按五段时代路线排列。每书有入门导读、可翻页卷目、上下卷、简繁字形切换、段落定位、分享、继续阅读和本书原文检索。入口 `?library=`；例如 `?library=houhanshu&volume=50#p2` 定位《后汉书》卷 50 的第二段。

- **全书导读**：130 卷、390 段阅读线索；8 条路线分别按初读人物、朝代更替、诸侯、汉朝治理、制度生活、年表、不同人物和原书顺序组织。支持按篇名、人物或问题搜索、按体例筛选、保存导读进度和分享当前段落。每段有对应原文入口，十表说明表格读法，八书解释制度主题。
- **白话故事**：6 篇、17 幕，依次为大泽乡、巨鹿、鸿门宴、韩信拜将、彭城、垓下。每篇介绍当时局面、人物身份、分幕经过、结果、回顾和词语解释，每幕可定位对应的原文段落。它是楚汉历史的入门选读，事件之间仍有其他历史过程。
- **边读边看**：故事星图只显示当前幕出现的人物、事件及已经选定的记载行动。连线可读成一句话；共同出现在篇章中，不会自动成为故事中的人物互动。切换下一幕时再更新图上内容。
- **再查原文**：130 卷正文保持原样，阅读器从同一份全书导读显示本卷摘要，并可返回完整分段导读。首次默认简体，尊重浏览器已保存的原字偏好。简体只转换字形，导读是概述，都不等于全书白话翻译。

## 运行与检查

使用 Node.js 24.x，或不低于 22.12 的 Node.js 22.x。

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

打开开发服务器打印的 HTTP 地址。生产构建输出到 `dist/`，可部署至静态服务器，无需 API 密钥、数据库或远程内容服务。建议服务器启用 Brotli/gzip；新增原文及检索索引约 257 MB，正文按卷加载，检索索引按书加载。本次仅修改本地项目，未部署。

## 《史记》全书接入

- **全文**：130 卷，12 本纪、10 表、8 书、30 世家、70 列传；十表保留正文表格，非仅收录序言。共 730,220 字符，包含转录校勘及编者增补，不等同于古代原作字数。
- **星图**：5,297 个人物词条、3,203 个事件、130 个篇章节点，29,276 条关联。每卷均有篇章、人物与事件入口。图谱按关联逐步探索，默认展开 12 个邻居，最多同时显示 50 个对象；全部数据均可检索。
- **阅读互通**：顶部“史记原文”打开目录；支持简繁检索、全文与年表搜索、原字/简体切换、段落定位、阅读书签、继续阅读、上下卷和链接分享。全书导读、故事、篇章、人物、事件可进入原文；阅读器将本卷人物事件索引默认折叠，需要时可展开并进入自由星图。
- **证据区分**：原文提及、篇章出处和互见单列“原文索引”；因果与事件衔接标记为解释。机器整理数据标示“待审校”，不会把共同提及当作已经核实的人物互动。
- **年代**：故事用所处时代、前后事件和必要年份解释先后顺序。自由探索不再提供时间轴或关系类型筛选，包含年代待考的内容。上古传统纪年及缺失年份仍保留不确定标记；卷一导读明确提醒上古传说和年代不确定性。

全书覆盖指固定版本的全文与结构化索引覆盖全部 130 卷，并不意味着已经穷尽所有历史事实或完成人物同名消歧。不同篇章对同一事件的叙述可能保留多个节点。原楚汉编辑样本的稳定 ID、6 个事件和 28 条关系继续用于故事与已有探索链接。

现有《史记》星图共 8,630 个实体、29,276 条关系和 130 项篇章来源。新增 23 部史书目前接入的是全文、卷目索引、书级导读和路线，尚未把每部书的全部人物、事件及关系审校成与《史记》同等粒度的星图。旧的“专题导览”“我的探索”及专题切换入口仍已移除。

## 新增 23 部史书

《汉书》《后汉书》《三国志》《晋书》《宋书》《南齐书》《梁书》《陈书》《魏书》《北齐书》《周书》《隋书》《南史》《北史》《旧唐书》《新唐书》《旧五代史》《新五代史》《宋史》《辽史》《金史》《元史》《明史》共 3,083 正卷，另收《陈书》序一篇。加上《史记》共 24 部、3,213 正卷。字符数是转录数据统计，非古代原作字数。

主要底本是 [Zinin 与 Xu 发布的二十四史研究语料](https://osf.io/tp729/)，据维基文库整理。该语料缺《后汉书》卷 50、51、《新唐书》卷 54、《宋史》卷 69；前两卷由 [gujilab 古典文献语料](https://github.com/gujilab/chinese-classical-corpus)补齐，后两卷由 [hunterhug 的公开转录](https://github.com/hunterhug/china-history)补齐。《宋史》13 卷缺录的宗室世系表与《旧五代史》3 处短卷改用维基文库单卷 EPUB 补充。至少 12 卷仍有历法表格省略，阅读页明确提示缺录。每卷阅读页链接到实际转录来源。卷名从公开目录提取，未能可靠匹配时显示卷号；提示文字仅供入门，未完成逐卷人工校勘。详见 [新增史书来源与重建说明](data/dynastic-histories/README.md)。

```bash
# 首次重建需下载固定来源快照，再校验哈希并生成原文与检索索引
npm run fetch:dynastic
npm run import:dynastic
npm run verify:dynastic
```

## 数据来源与重建

正文来自[维基文库《史记》及贡献者](https://zh.wikisource.org/wiki/史記)的固定 EPUB 存档，古代原作属公有领域；EPUB 标示 CC BY-SA 3.0/GFDL，部分页脚有 CC BY-SA 4.0 提示，详见 [全文来源说明](data/shiji/README.md)。本站保留校勘与编者小节，移除导航和危险 HTML，重新排版并添加段落编号。

结构化图谱来自[鲍捷及贡献者的史记知识库](https://github.com/baojie/shiji-kb)，采用 **CC BY-NC-SA 4.0 非商业许可**，快照与派生图谱保留署名和许可。商业使用需另获授权或替换这部分数据。详见 [图谱来源说明](data/shiji-graph/README.md)。

```bash
# 使用仓库内固定快照，校验 SHA-256 后离线重建
npm run import:shiji
```

原始快照在 `data/`；生成的全文在 `public/data/shiji/`，图谱及导入报告在 `src/domain/generated/`。转换不依赖上游在线 API；更新底本需要显式更新校验值并重新验证。

## 探索与本机记录

自由探索的 3D 星图支持旋转、缩放、平移、居中、全屏、展开/撤销关联和列表切换；可搜索全书人物、事件与篇章，并查看来源。全书导读和故事分别保存最近位置与已读记录；原文的最近位置、段落书签及显示偏好也保存在当前浏览器，无账号或跨设备同步。公开链接可定位导读分段、故事分幕、探索对象或原文卷次/段落，不会携带本机阅读记录。

现代浏览器需支持原生 dialog 和 WebGL 2。自由探索的 3D 失败时降级为列表，手机优先列表；故事即使不能显示 3D，人物和行动文字仍可阅读。阅读器支持手机布局，年表可横向滚动。自由探索保留三档画质、动态效果设置及系统减少动态偏好。

## 验证与边界

自动化检查覆盖全文与年表、HTML 清理、图谱引用、搜索、年代空值、单一史记专题、50 节点预算、链接、故事分幕数据及阅读加载竞态、重试、书签、简体偏好和索引折叠。它们不替代全量史料审校、真实手机性能和跨浏览器兼容性认证。完整图谱采用紧凑数据格式；生产构建仍会提示大块文件，首屏性能需在目标设备和托管环境测量。

当前的白话内容包括 6 篇《史记》故事与 130 卷独立入门导读，并为新增 23 部书提供书级简介和按卷读法提示；不是二十四史逐句译文。机器整理的《史记》图谱也没有完成逐条人工审核，新增史书更未生成全量人物事件关系图。历史解释仍需结合校勘本审读。本文描述仓库内功能和构建方式，不表示本次修改已经部署到服务器。

详细结构和审校边界见 [《史记》接入技术说明](史记接入技术说明.md)，交互检查见 [开发验收记录](开发验收记录.md)。原产品与 3D 设计文档作为后续迭代参考。
