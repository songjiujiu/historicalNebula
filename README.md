# 历史星云 · Historical Nebula

以 TypeScript、Vite、Flask 和 MySQL 构建的历史入门与二十四史阅读网站，历史主线从上古延伸到当代（本版节点选至2024年）。《史记》130 卷有逐卷入门导读；新增 23 部史书、3,083 个可阅读卷次，可沿历史主线、书目与卷次阅读，并在单部史书内检索已收录转录。少数历法表仍缺录。原文、白话正文和检索文件由后端接口从 MySQL 返回。

## 第一次阅读

首页默认进入“读懂历史”。主导航另有“史记导读”“二十四史导读”“清至当代导读”“史记原文”“二十四史原文”和“清至当代正文”，共七个入口。楚汉故事模块、推荐卡和史记星图已移除；旧故事与探索链接转到历史主线，合法原文段落锚点继续保留。

顶栏右侧可在黑夜模式与白天模式之间切换；选择保存在当前浏览器，重新打开或切换阅读入口时沿用。

首页现在提供一题互动阅读样板：“西晋明明统一了，为什么又分裂？”（`?question=western-jin`）。沿 280、316—318、420 三站切换，同屏看南北局势，逐站展开已有事件并定位原文，最后用三张卡片回顾。每站 URL 可分享；这是以已核验节点串起的入门选读，不把相邻节点断言为唯一因果链。

- **读懂历史**：15 段时代、32 个快速主线事件，可展开全部 74 个关键节点。每个事件解释当时局面、经过、影响、人物身份和一句记忆重点；南北朝、宋辽金等并立政权分行说明。53 条原文定位覆盖全部 24 部史书，点击可高亮到对应段落及摘句，并返回事件继续阅读。支持时代筛选、事件与人物搜索、前后事件、分享链接及本机已读进度。例如 `?journey=sui-unifies`；其陈书出处为 `?library=chenshu&volume=6&from=sui-unifies#p50`。事件主线是入门选读，并非全量事件库；相邻节点不代表唯一或直接的因果关系。

- **清到当代**：接续明末的 34 个事件，分为清朝前期、晚清、民国、1949年后的探索、改革开放与港澳回归、21世纪与当代六段。每个事件有“阅读正文”入口，打开对应白话篇章；共34篇、约1.85万字，正文与概要分开，按事件顺序衔接。目录 `?texts=chapters`，如 `?texts=chapters&article=hong-kong-return#p4`；支持小节、段落定位、篇内关键词查找、前后篇、返回导读、手机布局及浏览器前进后退。

- **清至当代导读**：独立入口 `?modern-guides=`，也可从正文目录进入。六段时代各有前后联系、阅读方法、术语与小结；34篇正文各有专属问题、人物身份、背景、三段阅读提示与记忆重点，共102条提示直达实际正文小节。比如 `?modern-guides=reform&step=hong-kong-return`，第二节进入 `?texts=chapters&article=hong-kong-return&from=hong-kong-return&guide=hong-kong-return#p4`；正文、关联《清史稿》或文献原文都可返回同篇导读。支持简繁关键词搜索、时代筛选、本机完成标记、继续上次、分享地址、前进后退与手机排版。当前覆盖已收录34篇白话正文，不代表《清史稿》529卷逐卷导读。

- **清代与近现代原文**：`?texts=qingshigao` 提供《清史稿》529卷目录，523卷有转录正文，其中卷29星表不完整，卷30—35正文缺录，均有提示。《清史稿》独立于二十四史。`?texts=documents` 收录11份文献正文，包括《中华民国临时约法》、国民党一大宣言、1949年中央人民政府公告、经济特区条例、港澳联合声明（含附件）、相关宪法修正案等。13条清史稿定位与文献定位均核验实际摘句；如 `?texts=documents&doc=hong-kong-declaration&from=hong-kong-return#p3`。简繁切换只改变显示字形。资料来源、许可、缺录与整理方法见 [正文来源说明](data/modern-history/README.md)。白话正文是本站综合编写，文件保留发布者立场与措辞；文献选读不等于收录清至当代全部史料。

- **二十四史导读**：入口 `?histories=`，24 部史书共用导读目录；《史记》仍进入原有 130 卷导读，新增 23 部各有时代背景、前后史书关系、阅读方法、术语解释和总结。关键事件复用已核验的历史主线，用“之前—发生了什么—后来”分段解释；仅展示当前史书的原文出处，支持节选预览、原文高亮与返回当前导读。含书名／人物搜索、时代筛选、单书事件进度、继续上次、链接分享及全书卷目筛选。比如 `?histories=yuanshi&step=yuan-unifies`，对应出处 `?library=yuanshi&volume=10&guide=yuan-unifies#p14`。这是全书入门与事件选读，不是新增 3,083 卷的逐卷导读。

- **二十四史原文**：从《汉书》到《明史》的 23 部新增史书按五段时代路线排列。每书有入门导读、可翻页卷目、上下卷、简繁字形切换、段落定位、分享、继续阅读和本书原文检索。入口 `?library=`；例如 `?library=houhanshu&volume=50#p2` 定位《后汉书》卷 50 的第二段。

- **全书导读**：130 卷、390 段阅读线索；8 条路线分别按初读人物、朝代更替、诸侯、汉朝治理、制度生活、年表、不同人物和原书顺序组织。支持按篇名、人物或问题搜索、按体例筛选、保存导读进度和分享当前段落。每段有对应原文入口，十表说明表格读法，八书解释制度主题。
- **再查原文**：130 卷正文保持原样，阅读器从同一份全书导读显示本卷摘要，并可返回完整分段导读。首次默认简体，尊重浏览器已保存的原字偏好。简体只转换字形，导读是概述，都不等于全书白话翻译。

## 运行与检查

使用 Node.js 24.x，或不低于 22.12 的 Node.js 22.x。

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
python -m pytest backend/tests
```

开发环境需要先启动 MySQL 与 Flask，设置 `HISTORY_DB_HOST`、`HISTORY_DB_PORT`、`HISTORY_DB_NAME`、`HISTORY_DB_USER`、`HISTORY_DB_PASSWORD`，再运行 Vite；详见 [后端与服务器部署说明](deploy/README.md)。生产构建输出到 `dist/`，其中只有网页资源，不包含 `public/data` 的 3,816 个 JSON 文件。数据从 `/api/v1/data/...` 获取；`/api/v1/health` 检查数据库是否有正在使用的数据版本。正文按卷加载，检索索引按书加载。

## 《史记》全书接入

- **全文**：130 卷，12 本纪、10 表、8 书、30 世家、70 列传；十表保留正文表格，非仅收录序言。共 730,220 字符，包含转录校勘及编者增补，不等同于古代原作字数。
- **阅读互通**：顶部“史记原文”打开目录；支持简繁检索、全文与年表搜索、原字/简体切换、段落定位、阅读书签、继续阅读、上下卷和链接分享。历史主线和全书导读可直接进入原文，原文也可以返回本卷导读。
- **年代与解释**：历史主线用所处时代、前后事件和必要年份解释顺序。上古传统纪年及缺失年份保留不确定标记；卷一导读明确提醒上古传说和年代不确定性。导读与原文区分展示。

全书覆盖指固定版本的原文覆盖全部 130 卷，并不意味着已经穷尽所有历史事实。历史图谱、故事源码与固定来源快照仍保存在仓库供溯源，但当前页面和生产脚本不再加载它们，也不再提供星图入口。

## 新增 23 部史书

《汉书》《后汉书》《三国志》《晋书》《宋书》《南齐书》《梁书》《陈书》《魏书》《北齐书》《周书》《隋书》《南史》《北史》《旧唐书》《新唐书》《旧五代史》《新五代史》《宋史》《辽史》《金史》《元史》《明史》共 3,083 正卷，另收《陈书》序一篇。加上《史记》共 24 部、3,213 正卷。字符数是转录数据统计，非古代原作字数。

主要底本是 [Zinin 与 Xu 发布的二十四史研究语料](https://osf.io/tp729/)，据维基文库整理。该语料缺《后汉书》卷 50、51、《新唐书》卷 54、《宋史》卷 69；前两卷由 [gujilab 古典文献语料](https://github.com/gujilab/chinese-classical-corpus)补齐，后两卷由 [hunterhug 的公开转录](https://github.com/hunterhug/china-history)补齐。《宋史》13 卷缺录的宗室世系表与《旧五代史》3 处短卷改用维基文库单卷 EPUB 补充。至少 12 卷仍有历法表格省略，阅读页明确提示缺录。每卷阅读页链接到实际转录来源。卷名从公开目录提取，未能可靠匹配时显示卷号；提示文字仅供入门，未完成逐卷人工校勘。详见 [新增史书来源与重建说明](data/dynastic-histories/README.md)。

```bash
# 首次重建需下载固定来源快照，再校验哈希并生成原文与检索索引
npm run fetch:dynastic
npm run import:dynastic
npm run verify:dynastic
```

## 数据来源与重建

正文来自[维基文库《史记》及贡献者](https://zh.wikisource.org/wiki/史記)的固定 EPUB 存档，古代原作属公有领域；EPUB 标示 CC BY-SA 3.0/GFDL，部分页脚有 CC BY-SA 4.0 提示，详见 [全文来源说明](data/shiji/README.md)。本站保留校勘与编者小节，移除导航和危险 HTML，重新排版并添加段落编号。

结构化图谱来自[鲍捷及贡献者的史记知识库](https://github.com/baojie/shiji-kb)，采用 **CC BY-NC-SA 4.0 非商业许可**，快照与派生图谱保留署名和许可。商业使用需另获授权或替换这部分数据。详见 [图谱来源说明](data/shiji-graph/README.md)。

```bash
# 使用仓库内固定快照，校验 SHA-256 后离线重建
npm run import:shiji
```

原始快照在 `data/`；生成的全文在 `public/data/shiji/`，图谱及导入报告在 `src/domain/generated/`。`public/data` 用于校验和导入 MySQL，不会复制到网页构建目录。转换不依赖上游在线 API；更新底本需要显式更新校验值并重新验证。

## 阅读与本机记录

历史主线与全书导读分别保存最近位置和已读记录；原文的最近位置、段落书签及显示偏好也保存在当前浏览器，无账号或跨设备同步。公开链接可定位事件、导读分段或原文卷次/段落，不会携带本机阅读记录。导读的“继续上次”保留在简介下方。

现代浏览器需支持原生 dialog。当前阅读页面不需要 WebGL，也不加载 Three.js、星图数据或故事场景。阅读器支持手机布局，年表可横向滚动。

## 验证与边界

自动化检查覆盖全文与年表、HTML 清理、事件出处、搜索、链接、阅读加载竞态、重试、书签及简体偏好；仓库中的历史图谱和故事数据检查仍保留。浏览器检查覆盖七个导航入口、旧链接回退及手机布局；清至当代新增导读目录、同页切换位置保持、正文与原文往返、进度恢复及34个直达链接检查。它们不替代全量史料审校与跨浏览器兼容性认证。原文字形转换和史书目录的按需加载文件仍有大块警告。

当前的白话内容包括跨二十四史的 40 个入门事件、清到当代的 34 个新增事件与《史记》130 卷独立入门导读，并为新增 23 部书提供结构化全书入门导读、关键事件选读与原文卷目读法提示；不是二十四史逐句译文。事件出处以底本的卷号、段号和摘句核验，摘要属于综合解释，不是摘句的逐句翻译；上古传说、争议和史书立场另作提示。历史解释仍需结合校勘本审读。

详细结构和审校边界见 [《史记》接入技术说明](史记接入技术说明.md)，交互检查见 [开发验收记录](开发验收记录.md)。原产品与 3D 设计文档作为后续迭代参考。
