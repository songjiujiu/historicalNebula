# 历史星云 · Historical Nebula

以 TypeScript 和 Vite 构建的二十四史阅读网站。《史记》130 卷有逐卷入门导读；新增 23 部史书、3,083 个可阅读卷次，可沿历史主线、书目与卷次阅读，并在单部史书内检索已收录转录。少数历法表仍缺录。

## 第一次阅读

首页默认进入“读懂历史”。主导航另有“史记导读”“二十四史导读”“史记原文”和“二十四史原文”，共五个入口。楚汉故事模块、推荐卡和史记星图已移除；旧故事与探索链接转到历史主线，合法原文段落锚点继续保留。

- **读懂历史**：9 段时代、15 个快速主线事件，可展开全部 40 个关键节点。每个事件解释当时局面、经过、影响、人物身份和一句记忆重点；南北朝、宋辽金等并立政权分行说明。53 条原文定位覆盖全部 24 部史书，点击可高亮到对应段落及摘句，并返回事件继续阅读。支持时代筛选、事件与人物搜索、前后事件、分享链接及本机已读进度。例如 `?journey=sui-unifies`；其陈书出处为 `?library=chenshu&volume=6&from=sui-unifies#p50`。事件主线是入门选读，并非全量事件库；相邻节点不代表唯一或直接的因果关系。

- **二十四史导读**：入口 `?histories=`，24 部史书共用导读目录；《史记》仍进入原有 130 卷导读，新增 23 部各有时代背景、前后史书关系、阅读方法、术语解释和总结。关键事件复用已核验的历史主线，用“之前—发生了什么—后来”分段解释；仅展示当前史书的原文出处，支持节选预览、原文高亮与返回当前导读。含书名／人物搜索、时代筛选、单书事件进度、继续上次、链接分享及全书卷目筛选。比如 `?histories=yuanshi&step=yuan-unifies`，对应出处 `?library=yuanshi&volume=10&guide=yuan-unifies#p14`。这是全书入门与事件选读，不是新增 3,083 卷的逐卷导读。

- **二十四史原文**：从《汉书》到《明史》的 23 部新增史书按五段时代路线排列。每书有入门导读、可翻页卷目、上下卷、简繁字形切换、段落定位、分享、继续阅读和本书原文检索。入口 `?library=`；例如 `?library=houhanshu&volume=50#p2` 定位《后汉书》卷 50 的第二段。

- **全书导读**：130 卷、390 段阅读线索；8 条路线分别按初读人物、朝代更替、诸侯、汉朝治理、制度生活、年表、不同人物和原书顺序组织。支持按篇名、人物或问题搜索、按体例筛选、保存导读进度和分享当前段落。每段有对应原文入口，十表说明表格读法，八书解释制度主题。
- **再查原文**：130 卷正文保持原样，阅读器从同一份全书导读显示本卷摘要，并可返回完整分段导读。首次默认简体，尊重浏览器已保存的原字偏好。简体只转换字形，导读是概述，都不等于全书白话翻译。

## 运行与检查

使用 Node.js 24.x，或不低于 22.12 的 Node.js 22.x。

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

打开开发服务器打印的 HTTP 地址。生产构建输出到 `dist/`，可部署至静态服务器，无需 API 密钥、数据库或远程内容服务。建议服务器启用 Brotli/gzip；新增原文及检索索引约 257 MB，正文按卷加载，检索索引按书加载。本次仅修改本地项目，未部署。

## 《史记》全书接入

- **全文**：130 卷，12 本纪、10 表、8 书、30 世家、70 列传；十表保留正文表格，非仅收录序言。共 730,220 字符，包含转录校勘及编者增补，不等同于古代原作字数。
- **阅读互通**：顶部“史记原文”打开目录；支持简繁检索、全文与年表搜索、原字/简体切换、段落定位、阅读书签、继续阅读、上下卷和链接分享。历史主线和全书导读可直接进入原文，原文也可以返回本卷导读。
- **年代与解释**：历史主线用所处时代、前后事件和必要年份解释顺序。上古传统纪年及缺失年份保留不确定标记；卷一导读明确提醒上古传说和年代不确定性。导读与原文区分展示。

全书覆盖指固定版本的原文覆盖全部 130 卷，并不意味着已经穷尽所有历史事实。历史图谱、故事源码与固定来源快照仍保存在仓库供溯源，但当前页面和生产脚本不再加载它们，也不再提供星图入口。

## 新增 23 部史书

《汉书》《后汉书》《三国志》《晋书》《宋书》《南齐书》《梁书》《陈书》《魏书》《北齐书》《周书》《隋书》《南史》《北史》《旧唐书》《新唐书》《旧五代史》《新五代史》《宋史》《辽史》《金史》《元史》《明史》共 3,083 正卷，另收《陈书》序一篇。加上《史记》共 24 部、3,213 正卷。字符数是转录数据统计，非古代原作字数。

主要底本是 [Zinin 与 Xu 发布的二十四史研究语料](https://osf.io/tp729/)，据维基文库整理。该语料缺《后汉书》卷 50、51、《新唐书》卷 54、《宋史》卷 69；前两卷由 [gujilab 古典文献语料](https://github.com/gujilab/chinese-classical-corpus)补齐，后两卷由 [hunterhug 的公开转录](https://github.com/hunterhug/china-history)补齐。《宋史》13 卷缺录的宗室世系表与《旧五代史》3 处短卷改用维基文库单卷 EPUB 补充。至少 12 卷仍有历法表格省略，阅读页明确提示缺录。每卷阅读页链接到实际转录来源。卷名从公开目录提取，未能可靠匹配时显示卷号；提示文字仅供入门，未完成逐卷人工校勘。详见 [新增史书来源与重建说明](data/dynastic-histories/README.md)。

```bash
# 首次重建需下载固定来源快照，再校验哈希并生成原文与检索索引
npm run fetch:dynastic
npm run import:dynastic
npm run verify:dynastic
```

## 数据来源与重建

正文来自[维基文库《史记》及贡献者](https://zh.wikisource.org/wiki/史記)的固定 EPUB 存档，古代原作属公有领域；EPUB 标示 CC BY-SA 3.0/GFDL，部分页脚有 CC BY-SA 4.0 提示，详见 [全文来源说明](data/shiji/README.md)。本站保留校勘与编者小节，移除导航和危险 HTML，重新排版并添加段落编号。

结构化图谱来自[鲍捷及贡献者的史记知识库](https://github.com/baojie/shiji-kb)，采用 **CC BY-NC-SA 4.0 非商业许可**，快照与派生图谱保留署名和许可。商业使用需另获授权或替换这部分数据。详见 [图谱来源说明](data/shiji-graph/README.md)。

```bash
# 使用仓库内固定快照，校验 SHA-256 后离线重建
npm run import:shiji
```

原始快照在 `data/`；生成的全文在 `public/data/shiji/`，图谱及导入报告在 `src/domain/generated/`。转换不依赖上游在线 API；更新底本需要显式更新校验值并重新验证。

## 阅读与本机记录

历史主线与全书导读分别保存最近位置和已读记录；原文的最近位置、段落书签及显示偏好也保存在当前浏览器，无账号或跨设备同步。公开链接可定位事件、导读分段或原文卷次/段落，不会携带本机阅读记录。导读的“继续上次”保留在简介下方。

现代浏览器需支持原生 dialog。当前阅读页面不需要 WebGL，也不加载 Three.js、星图数据或故事场景。阅读器支持手机布局，年表可横向滚动。

## 验证与边界

自动化检查覆盖全文与年表、HTML 清理、事件出处、搜索、链接、阅读加载竞态、重试、书签及简体偏好；仓库中的历史图谱和故事数据检查仍保留。浏览器检查确认五个导航入口、被移除模块不再加载、旧链接回退及手机布局。它们不替代全量史料审校与跨浏览器兼容性认证。二十四史目录的按需加载文件仍有大块警告。

当前的白话内容包括跨二十四史的 40 个入门事件与 130 卷独立入门导读，并为新增 23 部书提供结构化全书入门导读、关键事件选读与原文卷目读法提示；不是二十四史逐句译文。事件出处以本地底本的卷号、段号和摘句核验，摘要属于综合解释，不是摘句的逐句翻译；上古传说、争议和史书立场另作提示。历史解释仍需结合校勘本审读。本文描述仓库内功能和构建方式，不表示本次修改已经部署到服务器。

详细结构和审校边界见 [《史记》接入技术说明](史记接入技术说明.md)，交互检查见 [开发验收记录](开发验收记录.md)。原产品与 3D 设计文档作为后续迭代参考。
