## 公开演示与发行包

本次独立演示保留已有语料与用户生成媒体，并附带来源及许可说明。本次许可整理未替换正文、重建目录或移除媒体；软件发行包实际包含哪些文件，以各发行包清单为准。已知的原有许可条件继续适用，部分第三方来源仍待进一步核实，不能将完整演示或数据包称为“全部 MIT”。

下列内容是后续来源治理和可选演示范围的技术建议，不是本项目另加的发布前置要求。后续可以补充授权和制作记录，也可以发布只含功能介绍及外部链接的版本，或选择替换、暂不打包部分内容；这些选择均不改变来源方的既有许可条件。

### 可选方案：替换两处正文补卷

《新唐书》54 卷与《宋史》69 卷目前保留原有补卷。如后续决定替换，已找到可以核对的维基文库页面：

- [新唐書/卷054](https://zh.wikisource.org/wiki/新唐書/卷054)
- [宋史/卷069](https://zh.wikisource.org/wiki/宋史/卷069)

若采用此方案，可从这些页面取得固定版本或 EPUB，记录下载日期、来源页/修订版本、SHA-256 及实际许可，使用现有 EPUB 清理逻辑保留正文和表格，生成替代卷。只有实际换用新转录后才更改其来源标记。

替换时需要同步重建：

1. `public/data/histories/xintangshi/054.json` 和 `public/data/histories/songshi/069.json`。
2. 两本书 `search.json` 中相应卷的全文条目。
3. `src/domain/generated/dynastic-manifest.json` 中相应卷的块数、字符数、摘要、标题、来源和版本，以及每书统计。
4. 如后端使用替换后的正文，重新导入对应数据库版本；发行包可以只含新快照，若保留旧快照用于溯源则继续保留其单独的来源和待核验记录。

段落编号可能随底本变化，应重新检查指向两卷的引用与锚点。不要只替换 `sourceUrl` 或把原文件改名。

### 可选方案：提供部分正文的演示

若后续决定暂不打包两个补卷，不宜只删除正文 JSON：阅读器会加载该卷，且校验正文块数；搜索加载还会检查索引条目数等于目录章节数。直接删除会使对应阅读或全书搜索报错。

演示构建可保留对应卷的自写缺录说明，例如“演示版暂未提供本卷正文，请访问原始来源”，将正文设为一个说明块；相应目录条目的 `blocks` 改为 `1`、正文字符统计为 `0`、`excerpt` 置空、`incomplete` 标为 `true`，并更新来源说明。搜索索引保留该卷号但使用空 `blocks`，同时重算书级统计。这样可保留目录与前后卷导航，并明确展示演示范围；需要以该演示配置运行阅读和搜索验证，不应冒用完整语料测试已通过的结论。

### 来源治理与署名维护

- 后续核验可同时覆盖 `indexes.json` 与 `catalog-titles.json` 派生的卷名/体例。若决定替换目录来源，可以使用已核实来源的标题或自行生成的“卷 N”；仅移除原始目录文件不会改变已有派生标签的来源。
- 若决定更换模型所嵌正文，可同步重建相关图片、GLB 或 Blender 文件，或在特定演示包中省略相应模型。无需 3D 的版本也可使用纯 HTML/CSS 和自有图形；本次演示保留现有媒体。
- 当前界面不加载 CC BY-NC-SA 图谱；演示包也可不包含该快照和派生图谱。源码归档若仍保留这些文件，继续附带其原有署名和许可，不能声称源码归档完全采用 MIT。
- 完整演示应提供能在页面上访问的来源/许可说明，并随离线包保留对应文件；构建时不要丢弃许可证和依赖 NOTICE。
- 使用当前公开服务器的链接不会把该服务器的内容核验状态改为“全部已确认许可”。发布说明如实记录实际保留、替换或省略范围，以及尚待核验的来源。

## 新增或更新来源

新增资料时记录作者/发布机构、原始 URL、固定版本/日期、文件哈希、许可版本、实际修改和输出路径。对来源不明或只写“公开可用”的材料，不自动推断为 MIT、CC0 或公有领域。

更换来源后同步更新数据说明、页面出处、检索数据、清单与本文件中的状态；检查生成文件和数据库副本是否仍带有旧内容。代码贡献和内容贡献分别说明权利来源，引用第三方材料时保留其原有声明。
